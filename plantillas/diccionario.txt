# DICCIONARIO FUNCIONAL CORPORATIVO
# ---------------------------------------------------------------------------
# Este fichero alimenta la funcionalidad "Habla con tus datos". El LLM lo
# usa como vocabulario oficial de la compañía para:
#   (1) entender sinónimos / expresiones internas,
#   (2) saber cómo presentar cada dato,
#   (3) calcular KPIs derivados con fórmulas verificables.
#
# Cada ENTRADA es un bloque separado por línea en blanco:
#
#   <Nombre canónico tal como lo devuelve la API>
#   Definicion: <texto libre: qué es y cómo interpretarlo>
#   Sinonimos: <terminos separados por ';' - uso interno, alias, inglés...>
#   Presentacion: <instrucciones: en millones, con % sobre ingresos, con
#                  desglose por segmento, acumulado o periodo, etc.>
#   Formula: <solo para KPIs derivados: expresión con partidas entre [ ],
#            operadores + - * / y paréntesis. Ejemplo:
#            [EBITDA] / [Ingresos totales] * 100>
#   Tags: <palabras clave separadas por ',' para agrupar entradas>
#
# Reglas:
#   - Todos los campos son OPCIONALES (puedes rellenar solo Sinonimos, o
#     solo Presentacion, o lo que te interese).
#   - Las líneas que empiezan por "#" son comentarios y se ignoran.
#   - El nombre canónico debe coincidir EXACTAMENTE con el de la API para
#     que el resolver sepa qué dato tomar. Para desambiguar duplicados entre
#     estados usa un prefijo: pyg., balance. o cashflow.
#     Ejemplo: cashflow.Beneficio neto de operaciones continuadas
#
# Ubicación esperada: Empresas/{TICKER}/diccionario.txt
# Este fichero es la PLANTILLA — cópialo a la carpeta de cada empresa y
# rellena lo que proceda.

# ===========================================================================
# KPIs Y FÓRMULAS DERIVADAS
# ---------------------------------------------------------------------------
# Añade aquí los indicadores calculados. El resolver sustituirá cada [X] por
# el valor numérico de esa partida (en el periodo que indique la pregunta,
# por defecto el último FY cerrado) y evaluará la expresión.
#
# Operadores soportados: + - * / ( )
# Para desambiguar duplicados entre estados: [pyg.X] / [balance.X] / [cashflow.X]
#
# Ejemplos comentados (quita el '#' inicial para activarlos):
# ===========================================================================

# Margen EBITDA
# Definicion: Rentabilidad operativa antes de amortizaciones sobre ingresos.
# Sinonimos: EBITDA margin
# Formula: [EBITDA] / [Ingresos totales] * 100
# Presentacion: Un decimal, formato porcentaje. Comparar vs ejercicio anterior.
# Tags: kpi, rentabilidad

# Margen neto
# Definicion: Porcentaje del beneficio neto sobre ingresos.
# Sinonimos: net margin
# Formula: [Beneficio neto] / [Ingresos totales] * 100
# Presentacion: Un decimal, formato porcentaje.
# Tags: kpi, rentabilidad

# Payout ratio
# Definicion: Porcentaje del beneficio distribuido como dividendo.
# Sinonimos: ratio de reparto
# Formula: [Dividendos pagados en efectivo] / [Beneficio neto] * 100
# Presentacion: Un decimal, formato porcentaje. Marcar como anomalía si >100%.
# Tags: kpi, retribucion

# DFN sobre EBITDA
# Definicion: Años teóricos de EBITDA necesarios para repagar la deuda neta.
# Sinonimos: Deuda neta / EBITDA; NFD / EBITDA; apalancamiento
# Formula: [Deuda neta] / [EBITDA]
# Presentacion: Un decimal con sufijo "x" (ej: 2,3x). Semáforo: <2 bajo, 2-4 medio, >4 alto.
# Tags: kpi, apalancamiento

# Ratio de liquidez
# Definicion: Cobertura de los pasivos a corto plazo con los activos corrientes.
# Sinonimos: current ratio
# Formula: [Activos corrientes] / [Pasivos corrientes]
# Presentacion: Dos decimales. Saludable típicamente entre 1,0 y 2,0.
# Tags: kpi, liquidez

# Conversión de caja
# Definicion: Qué porcentaje del EBITDA se convierte en caja operativa.
# Sinonimos: cash conversion
# Formula: [Flujo de caja operativo] / [EBITDA] * 100
# Presentacion: Un decimal, formato porcentaje.
# Tags: kpi, caja

# ROE
# Definicion: Rentabilidad sobre fondos propios.
# Sinonimos: return on equity
# Formula: [Beneficio neto] / [Patrimonio neto total] * 100
# Presentacion: Un decimal, formato porcentaje.
# Tags: kpi, rentabilidad

# ROA
# Definicion: Rentabilidad sobre activos totales.
# Sinonimos: return on assets
# Formula: [Beneficio neto] / [Activos totales] * 100
# Presentacion: Un decimal, formato porcentaje.
# Tags: kpi, rentabilidad
